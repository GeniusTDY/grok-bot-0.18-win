Grok Bot 0.18 Reconstructed - Windows x64
================================================

This is an unofficial Windows port built on:
https://github.com/b-nnett/grok-bot-0.18-reconstructed

First-time setup:

1. Install and start Docker Desktop.
2. Install a current Codex client.
3. Run: codex login
   Complete the browser sign-in with your own ChatGPT/Codex account.
4. Close any running reconstructed Grok Bot app.
5. Run Install.cmd from this extracted directory.
6. Open the desktop shortcut: Grok Bot 0.18 Reconstructed
7. In Settings -> Router, select Codex and enable Use local Docker VM.
8. Start a new conversation and ask Grok Bot to perform an action in the VM.

No Codex credentials, account IDs, tokens, or transcripts are included in this
archive. Your local Codex profile is read only at runtime and is never copied
into the application package or Docker image.

Source, security notes, and complete documentation:
https://github.com/tombionlikasongo-hub/grok-bot-0.18-reconstructed-win
